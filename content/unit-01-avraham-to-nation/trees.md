# Trees

```
THE FAMILY OF AVRAHAM
Terah
├─ Nahor
├─ Haran ─ Lot
└─ Avraham
   ├─ + Hagar (Egyptian) → Yishmael ...... Islamic tradition traces Muhammad here
   └─ + Sarah → Yitzchak
                └─ + Rivka → Esau (Edom)
                            → Yaakov (Israel)
                               ├─ Leah ..... Reuben, Simeon, Levi, Judah, Issachar, Zebulun (+ Dinah)
                               ├─ Zilpah ... Gad, Asher
                               ├─ Rachel ... Joseph (→ Manasseh, Ephraim), Benjamin
                               └─ Bilhah ... Dan, Naphtali
```

```
FROM FAMILY TO NATION
Family ........ Genesis 46: 70 persons of Jacob's household
People ........ Exodus 1: "the Israelite people," feared by Pharaoh
Nation ........ freedom (Exodus) → sea → manna → laws (Sinai) → Mishkan → land (Jordan)
```

```
HOW THE COVENANT DEVELOPS
Genesis 12 .... the call: leave home; promises of nation, blessing, name
Genesis 15 .... descendants will be strangers and slaves, then return (15:16)
Brit milah .... the covenant's sign (your notes: "maybe Avraham is the first Jew")
Sinai ......... a whole people: "if you obey… a kingdom of priests"; "we will do and obey"
Deut. 27 ...... renewed 40 years later: "This day you have become the people"
```

```
HOW A TRADITION DEVELOPS
Torah → rabbinic interpretation → tradition → Jewish history
e.g. Simchat Torah (not in the Torah): finish Devarim, restart Bereishit
```
